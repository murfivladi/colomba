# Colomba

**Медленный веб-мессенджер.** Каждое письмо несёт курьер — птица, животное, исторический транспорт или почта — и идёт ровно столько, сколько шёл бы этот курьер по настоящему маршруту между отправителем и получателем.

*Il messenger lento: ogni lettera la porta un corriere, e viaggia esattamente quanto viaggerebbe lui.*

Адрес: `vladinc.ru/colomba` · Языки: русский и итальянский · Бесплатно, без рекламы, без реальных денег.

## Что внутри

| Часть | Технологии |
|---|---|
| `shared/` | Каталог курьеров и тарифов, гео-математика, тексты уведомлений RU/IT — общие для сервера и клиента |
| `server/` | Node.js + TypeScript, Fastify, MariaDB/MySQL (POINT + пространственные индексы), планировщик, SSE, Web Push |
| `web/` | React + Vite + TypeScript, PWA (Service Worker, установка на экран), MapLibre GL с «пергаментным» стилем |

### Курьеры и доставка
- 13 курьеров в четырёх разделах + сезонные (олени зимой, аист весной); все параметры правятся в админке.
- **Маршруты:** птицы — дуга большого круга с облётом горных массивов (граф видимости; если обход длиннее в 1,5 раза — перелетают хребет); конь, собаки, улитка, «Почта» — OpenRouteService → GraphHopper → дуга ×1,3; парусник, дельфин, бутылка — `searoute-ts` офлайн; альбатрос предпочитает море. Кэш маршрутов по сетке ~5 км. Суша между континентами определяется по Natural Earth (Сицилия и Британия «склеены» с материком через проливы).
- **Время:** считается на сервере при отправке и показывается до неё (токен расчёта гарантирует, что срок не изменится): ночёвки по реальному восходу/закату в точке маршрута, сова — только ночью, «Почта» — часы работы и сортировка, погода Open-Meteo, миграция (+10%), разброс ±10%, опыт курьера (до +10%), шторма, потери 0,2%.
- Клиент двигает курьера по карте сам по временной шкале рейса, без запросов к серверу.

### Письма, люди, игра
Черновики, бумага/шрифты/марки/наклейки, фото, голос, рисунки от руки; анимация вскрытия по виду письма; отзыв в первые 5 минут; ответ тем же курьером, открытки; курьер ждёт ответа 7 дней и возвращается; очередь «когда вернётся»; отправка по времени и «чтобы пришло к дате»; рассылка нескольким; «бутылка в море»; штемпели городов и альбом стран; шкатулка.
Друзья по @нику, QR и ссылке, из контактов (Contact Picker API), поиск друзей по переписке. Детский режим (до 14 лет, профиль создаёт родитель, каждого друга одобряет родитель). Жалобы, блокировки, баны. Зёрнышки с защитой от фарма, достижения, задания на редких курьеров, лавка. Админ-панель: курьеры/тарифы/предметы/события/достижения, жалобы, статистика, рассылки от почтмейстера, приглашения в бету.

## Разработка

Нужны Node 20+ и MariaDB 10.6+ (или MySQL 8).

```bash
npm install
```

```bash
mysql -e "CREATE DATABASE colomba CHARACTER SET utf8mb4; CREATE USER colomba@localhost IDENTIFIED BY 'colomba'; GRANT ALL ON colomba.* TO colomba@localhost; GRANT ALL ON colomba_test.* TO colomba@localhost;"
```

```bash
cp server/.env.example server/.env && npm run build -w shared && npm run dev:server
```

```bash
npm run dev:web
```

Откройте http://localhost:5173/colomba/. Миграции и стартовые данные применяются при запуске сервера. Без SMTP коды входа пишутся в лог сервера. Сделать себя администратором: `npm run make-admin -w server -- you@example.com`.

Тесты (юнит + полный HTTP-сценарий жизни письма, нужна база `colomba_test`):

```bash
npm test
```

## Развёртывание (GitHub Actions)

Схема: фронт (PWA) — на shared-хостинге `vladinc.ru/colomba` по FTP; бэкенд, MariaDB и файлы — в Docker на VPS (`https://colomba-api.vladinc.ru:5576`, HTTPS бэкенд обслуживает сам, сертификатом Let's Encrypt).

**Браузер обращается только к `vladinc.ru/colomba/api`.** Там лежит PHP-прокси (`web/public/api/index.php`), который пересылает запросы на бэкенд: метод, тело (включая загрузку фото и голоса), cookie сессии, ответ — потоком (файлы и уведомления SSE без буферизации). Бэкенд принимает запросы только с общим секретом `PROXY_SECRET` (заголовок `X-Colomba-Proxy`), кроме `/api/health`, — в обход прокси к API не обратиться. На хостинге нужен PHP 7.4+ с расширением `curl`.

Workflow `.github/workflows/deploy.yml` запускается при пуше в `main` или вручную (Actions → Deploy → Run workflow). Порядок шагов:
1. Тесты и проверка типов.
2. **Бэкенд.** Архив кода уходит на VPS по SCP, затем по SSH (с паролем) запускается `deploy/remote-deploy.sh`. Скрипт:
   - при первом запуске ставит Docker и certbot;
   - создаёт `/opt/colomba/.env` со случайными паролями базы; дальше пароли сохраняются, а остальные настройки обновляются из секретов;
   - выпускает сертификат для `colomba-api.vladinc.ru` через `certbot --standalone`. **На время выдачи nginx останавливается и затем запускается обратно** (хуки `deploy/certbot-pre.sh` и `certbot-post.sh`). Если nginx не работал до этого, он не запускается. Хуки сохраняются в конфиге продления certbot, поэтому автопродление ведёт себя так же. Если сертификату ещё далеко до истечения, certbot ничего не делает и nginx не трогается;
   - копирует сертификат бэкенду (`/opt/colomba/certs`, хук `certbot-deploy.sh`; после продления он же перезапускает контейнер `colomba-api`);
   - выполняет `docker compose up -d --build` и ждёт, пока ответит `/api/health`.
3. **Фронт и прокси.** Сборка PWA (API — относительный адрес `/colomba/api`), генерация `api/config.php` с адресом бэкенда и `PROXY_SECRET` (в репозитории его нет, отдавать его запрещено `.htaccess`), выгрузка `web/dist/` по FTP и проверка `https://vladinc.ru/colomba/api/health` через прокси.

### Настройки в админке
Всё, что не нужно для запуска, меняется в **Админ-панель → Настройки** без перезапуска и без деплоя:
- почта (SMTP-сервер, порт, SSL, логин, пароль, отправитель) с кнопкой тестового письма;
- ключи OpenRouteService и GraphHopper, погода — с кнопкой проверки ключей;
- закрытая бета, почты администраторов, адрес приложения, контакт VAPID;
- игровые параметры: слоты, окно отзыва, ожидание ответа, шанс потери, разброс, бонусы, награды зёрнышками.

Значение из админки важнее `.env`; кнопка «Сбросить к .env» возвращает значение из файла. Пароли и ключи хранятся в базе зашифрованными (AES-256-GCM, ключ — `SETTINGS_KEY` из `.env` или производный от пароля базы) и в интерфейс не возвращаются, видна только маска. Порог детского режима (14 лет) задан законом и в админке не меняется. В `.env` остаётся только нужное для старта: база, порт, TLS, CORS, cookie.

### Секреты репозитория
| Секрет | Обязателен | Что это |
|---|---|---|
| `VPS_IP`, `VPS_USER` (`root`), `VPS_PASS` | да | SSH-доступ к VPS |
| `FTP_HOST`, `FTP_USER`, `FTP_PASS` | да | FTP shared-хостинга |
| `PROXY_SECRET` | да | общий секрет PHP-прокси и бэкенда, не короче 24 символов: `openssl rand -hex 32` |
| `FTP_DIR` | нет | каталог приложения на FTP, по умолчанию `/colomba/` (например, `/public_html/colomba/`) |
| `CERTBOT_EMAIL` | нет | почта для уведомлений Let's Encrypt |
| `ADMIN_EMAILS` | для первого входа | почта первого администратора; остальное (SMTP, ключи API) удобнее задать потом в админке |
| `ORS_API_KEY`, `GRAPHHOPPER_API_KEY`, `SMTP_URL`, `MAIL_FROM` | нет | то же можно задать в админке, она важнее |

### Что должно быть готово заранее
- DNS: A-запись `colomba-api.vladinc.ru` указывает на IP VPS.
- Порты 80 (только на время выдачи сертификата) и 5576 открыты. Если на VPS включён `ufw`, скрипт откроет их сам; облачный файрвол провайдера нужно настроить вручную.
- Cookie сессии ставится для `vladinc.ru` с путём `/colomba` (через прокси сайт и API — один адрес), CORS не нужен.

### Потом
- Полная база городов для штемпелей: на VPS `cd /opt/colomba/app && docker compose -p colomba exec api ...` либо локально `deploy/import-geonames.sh` с доступом к базе. Без неё работает стартовый набор из ~170 городов.
- Стать администратором можно так: указать свою почту в `ADMIN_EMAILS` до регистрации.
