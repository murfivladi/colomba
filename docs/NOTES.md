# Заметки по реализации

## Соответствие ТЗ и принятые решения
- **Открытые вопросы ТЗ — значения по умолчанию** (меняются в `shared/src/couriers.ts` → `GAME` / админке): ожидание ответа 7 дней, окно отзыва 5 минут, улитка и черепаха не ограничены по дальности — интерфейс честно показывает срок и просит подтверждения, если путь дольше 30 дней.
- **Автофильтр фото от незнакомцев** не реализован: только ручная модерация (жалоба → удаление письма/бан). Решение за заказчиком.
- **Таблицы `drafts`, `scheduled_letters`, `send_queue`** из модели данных реализованы как статусы `letters` (`draft` / `scheduled` / `queued`) — меньше дублирования.
- **Рассылка нескольким:** по одному курьеру на каждого адресата (у каждого письма свой рейс), ответы приходят лично.
- **«Бутылка в море»:** при отправке выбирается случайный взрослый (с включённой опцией), до которого есть морской путь; бутылка одноразовая и не возвращается. После получения появляется связь «друзья по переписке».
- **Ответ почтмейстеру** при онбординге: голубь долетает до станции в Вене, почтмейстер отвечает тем же голубем — новичок видит полный круг письма.
- **Погода** берётся при отправке и применяется ко всему рейсу; пересчёт в пути не делается (время не меняется, как требует ТЗ).
- **Потеря письма:** решается при отправке (0,2% × опыт). Отправитель видит обычный полёт до расчётного времени, затем «курьер задерживается»; курьер возвращается через 1–3 дня позже без письма.
- **Звуки курьеров** синтезируются Web Audio — без аудиофайлов и лицензий. Push-уведомления различаются вибрацией; кастомный звук системного уведомления браузеры не поддерживают.
- **Карта:** тайлы OpenFreeMap (бесплатно, без ключа). Если они недоступны из России, можно поднять свой сервер тайлов (Protomaps/PMTiles) на VPS и поменять URL в `web/src/map/parchment.ts`.
