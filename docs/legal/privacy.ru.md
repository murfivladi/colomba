# Политика конфиденциальности Colomba

**Черновик для проверки юристом. Не является юридической консультацией.**

Colomba — некоммерческий хобби-проект: бесплатно, без рекламы, без платежей и без внешней аналитики.

## Кто обрабатывает данные
Оператор: владелец сервиса vladinc.ru (контакты — в разделе «О приложении»).

## Какие данные мы собираем и зачем
| Данные | Зачем |
|---|---|
| Почта, хеш пароля, ключи доступа (passkeys) | Вход в аккаунт |
| Имя, @ник, аватар, «о себе», интересы, языки | Профиль, поиск друзей |
| Дата рождения | Проверка возраста: до 14 лет — только детский профиль, созданный родителем |
| Геолокация (последняя известная точка) | Расчёт маршрута и времени доставки письма |
| Письма, фото, голосовые, рисунки | Доставка писем адресату; хранение в «шкатулке» |
| Друзья, блокировки, жалобы | Работа сервиса и безопасность |
| Технические данные сессии (cookie) | Поддержание входа |

## Геолокация
Местоположение запрашивается только с вашего явного согласия. Точные координаты хранятся только на сервере и **никому не показываются**. Другие пользователи видят то, что вы выберете: город, страну или только расстояние; на карте точка смещается. У детей — не точнее города при любых настройках.

## Где хранятся данные
Все данные хранятся на сервере в Российской Федерации (152-ФЗ). Для пользователей из ЕС это означает передачу данных в страну, в отношении которой нет решения ЕС об адекватности уровня защиты. **Механизм передачи (например, явное информированное согласие) должен определить юрист** — это главный открытый вопрос.

## Внешние сервисы
Для расчёта маршрутов и погоды сервер передаёт **только координаты точек маршрута, без имён и иных данных**:
- OpenRouteService (HeiGIT, Германия) — маршруты по дорогам;
- GraphHopper (Германия) — резервный расчёт маршрутов;
- Open-Meteo (Швейцария) — погода по маршруту.
Карта загружается с OpenFreeMap (тайлы OpenStreetMap).

## Дети
Пользователи младше 14 лет могут пользоваться Colomba только в детском режиме: профиль создаёт родитель из своего аккаунта, каждого друга одобряет родитель, данные о ребёнке минимальны.

## Сроки хранения
Переписка хранится, пока существует аккаунт («шкатулка»). Коды входа — 15 минут, сессии — 90 дней.

## Ваши права
Вы можете изменить данные в настройках, скачать копию своих данных (кнопка «Скачать мои данные») и удалить аккаунт. При удалении аккаунта **ваши письма остаются у получателей, а автор анонимизируется**; профиль, место, курьеры, черновики и подписки удаляются.

## Cookie
Используется одна техническая cookie сессии. Рекламных и аналитических cookie нет.
